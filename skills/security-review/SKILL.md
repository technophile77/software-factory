# Security review

The criteria live in one place: `docs/security-standards.md`. Read it now and
use it as written. Do not restate or extend the criteria here, so the
developer and the security reviewer always apply the same rules.

## When the developer uses this
Before finishing each meaningful change, check it against S1 to S9. Fix what
you can. Anything you cannot fix, or that needs a decision, goes in your
completion report.

## When the security reviewer uses this
Follow the Gate 1 or Gate 2 checklist in the standards doc and report every
finding with its criterion id.
